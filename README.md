# AI Quota Guard — Micro-SaaS MVP

Zero-backend, privacy-first multi-model AI spend & burn-rate studio (Gemini 4 Neon, GPT-6.2 Sol/Astra, Claude Sonnet/Opus).

## Deploy in 30 Seconds (Zero Server Cost)
- **Cloudflare Pages**: `npx wrangler pages deploy . --project-name ai-quota-guard`
- **Vercel**: `npx vercel --prod`
- **Local Preview**: Open `index.html` in any browser or run `python -m http.server 8080`.

## Monetization Hook
Replace the `proBtn` click handler in `index.html` with your Lemon Squeezy or Stripe Payment Link ($9/mo or $29 lifetime).
